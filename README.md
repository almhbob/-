# JUMBAK | جمبك

تطبيق ركشات حديث لمنطقة رفاعة — تجربة شبيهة بأوبر ومصممة للبيئة المحلية في السودان.

> هذا المستودع تم تهيئته كبداية تنفيذية لمشروع جمبك، ويمكن لاحقًا إعادة تسميته إلى `jumbak` من إعدادات GitHub.

## الرؤية
جمبك يربط الراكب بأقرب سائق ركشة داخل رفاعة بطريقة سهلة، سريعة، وآمنة، مع تسعير واضح وتجربة عربية احترافية.

## المكونات

- `apps/mobile` تطبيق الراكب والسائق
- `apps/admin` لوحة الإدارة
- `server` الخادم وواجهات API
- `docs` التوثيق

## الوظائف الأساسية

### الراكب
- تسجيل الدخول برقم الهاتف
- تحديد نقطة الانطلاق والوجهة
- حساب سعر تقديري
- طلب أقرب ركشة
- متابعة حالة الرحلة
- الاتصال بالسائق
- تقييم الرحلة
- سجل الرحلات

### السائق
- تسجيل بيانات السائق والركشة
- تفعيل/إيقاف استقبال الطلبات
- قبول أو رفض الرحلة
- بدء وإنهاء الرحلة
- عرض الأرباح اليومية

### الإدارة
- إدارة المستخدمين والسائقين
- اعتماد السائقين
- إدارة المناطق والأسعار
- متابعة الرحلات والشكاوى
